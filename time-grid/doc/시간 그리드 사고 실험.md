# 시간 그리드 사고 실험

2026-10-23 기준

## 개요와 진행 원칙

이 실험은 시간, 공간, 빛, 중력을 그리드 사이의 에너지 전달 하나로 설명할 수 있는지를 시험한다. 현재 결론: 정지한 물질 주변에서 시간 몫과 공간 몫의 비 1, 빛의 중력 원천 2배는 격자 측정에서 나왔고, 장 쪽 비율 하나가 아직 가정으로 남아 있다. 시험 2에서 비 1(γ = 1)은 이름표로 지울 수 없는 물리적 조건 하나임이 확인됐다. 시험 3-a에서 원천에 압력을 넣으려면 벽 응력까지 넣어야 한다는 것(폰 라우에 조건)이 확인됐다. 시험 4에서 막의 변형 U가 스칼라(그리드마다 값 하나)이면 움직이는 이름표와 맞는 원천은 ρ−Σp뿐이라 빛이 중력을 만들지 못하고 γ = 1과 모순된다는 것이 나왔다. 장 쪽 비율(시간 몫 ρ+Σp, 공간 몫 ρ)을 얻으려면 막의 변형이 방향을 가진 텐서여야 한다. 텐서 1단계에서 26개 막이 받는 방향별 하중이 저장 파동의 응력 텐서(성분 6개)를 정확히 담는다는 것이 확인됐다. 텐서 2단계에서 이웃 막 결합 에너지 중 이름표 바꾸기(그리드 밀기)와 무관한 것은 하나뿐이며, 그것이 선형화된 아인슈타인 에너지와 같다는 것이 나왔다. 텐서 3단계에서 이름표 바꾸기를 시공간(틱 다시 매기기, 움직이는 이름표)으로 넓히면 시계 몫과 막의 맞물림, 시계 몫의 에너지, 운동 에너지 비까지 모두 유일하게 정해지고, 그 결과 정지 물질 주변에서 γ = 1과 1/r 장이 나온다. 막이 자기 자연 길이로 돌아가려는 스프링은 측정 원칙에 어긋나며, 있으면 먼 거리에서 장이 뒤집히고 거리에 비례해 커진다. 동역학 1에서 그 규칙이 만든 장을 그리드 재료값으로 바꿔 격자 위로 파속을 보냈더니, 파속이 물질 쪽으로 끌려 휘었고 휨이 속도에 따라 1 + γv²(잰 γ = 1.04)로 커져 빛 극한에서 뉴턴 값의 약 2배가 됐다. 동역학 2-a에서 3D 격자의 막 변형파가 + / × 두 편광으로만 퍼지고, 이름표 성분은 출렁이지 않는다는 것이 확인됐다. 동역학 2-c에서 저장 파동 덩어리가 자기 중력으로 스스로 묶이고(처음 나온 묶인 물체), 그런 덩어리 둘이 서로 끌려 케플러 궤도를 돈다는 것이 확인됐다. 동역학 2-b-1에서 그 궤도를 흉내 낸 원천을 3D 격자에 두자 막 변형파가 4중극 모양(정면 + / × 같은 세기, 측면 + 절반·× 0)으로 퍼졌고, 세기가 정적 장에서 잰 같은 G(= 1/32π)의 4중극 공식과 1.5% 안에서 맞았다(정적 G = 동적 G). 단, 원천이 보존될 때만 그렇다: 운동 응력만 넣으면 정확히 절반이 나오고, 두 덩어리를 묶는 장 자신의 응력과 덩어리 내부의 조석 응력까지 넣어야 전부가 나온다.

선형 약한 장에서 장 쪽 비율은 이제 가정이 아니라 "시공간 이름표 무관 + 이웃 막 결합 + 중력 쪽도 움직이는 이름표를 따름"의 결과다. 마지막 조건(중력 쪽도 빛과 같은 움직이는 이름표를 따름)은 아직 가정이다.

진행 방향: GR이 그리드 규칙에서 창발하는지 보이는 것(방향 A)을 목표로 한다. 텐서 규칙을 손으로 넣지 않고 저장 파동과 막의 역학에서 끌어내야 의미가 있다.

- 모든 주장은 지지 근거와 반론을 같은 비중으로 두고, 검증도(매우 높음 / 높음 / 중간 / 낮음 / 논리적 평가)를 붙인다.
- 인지를 제외한다. 시간은 공통 틱 없이 그리드의 에너지 저장과 이동에서 창발하는 개념으로 다룬다.
- 그리드 수는 변하지 않고(팽창 없음), 모든 그리드는 같은 연결 수를 가진다.
- **측정 원칙: 그리드 번호는 의미가 없고, 시계 틱과 틱으로 잰 홉만 의미가 있다.** 원시 홉 수는 표현에 따라 달라지므로(시험 1) 홉은 건너는 데 걸린 틱으로 센다. 파동으로 만든 시계와 자로는 움직임을 감지할 수 없으므로(시험 4, 연속 극한) 움직이는 관측자의 이름표 바꾸기도 이 원칙에 포함된다. 막에는 고유한 자연 길이가 없다(텐서 3단계): 고유 길이가 있으면 틱과 무관한 절대 자가 생겨 원칙에 어긋난다.
- 일반상대성이론과 다른 예측이 나오기 전까지 이 모형은 검증 불가능한 재서술로 본다.
- **공개 계획:** 이 사고 실험 전체를 나중에 웹페이지로 만들어, 사람들이 실험 과정을 전부 확인하고 결과를 쉽게 이해하도록 시각화한다. 모든 실험은 이를 염두에 두고 진행한다(아래 "웹페이지 시각화 계획").

## 현재 그리드 규칙

현재 모형은 결합된 공동(그리드)의 파동 모형이다. 이전의 문턱 발화 규칙은 전면 대체됐다.

1. 그리드는 에너지를 전달한다.
2. 그리드와 그리드 사이의 막의 떨림으로 연결된 그리드에 에너지가 전달된다.
3. 에너지 저장은 막이 아닌 내부의 파장값이며, 받은 파장은 막을 떠나기 전까지 내부에서 파동으로 저장된다.

핵심 해석과 예상:

- 파동의 이동이 시간을 창발한다. 시간은 파동의 통과(위상)로 센다.
- 저장된 파동이 커질수록 주변 파동이 굴절되고, 일정 이상이면 파동이 빠져나가지 못하는 구간이 생긴다.
- 안쪽에서 보면 바깥 시간이 빠르게 흐르고, 바깥에서 보면 안쪽 신호가 점점 늦어져 내부와 외부를 격리하는 막처럼 보인다.
- 창발한 시간 안에서 에너지가 이동한 결과가 공간을 만든다.
- **예상 (중력의 기원):** 중력은 시간과 공간이 만들어진 뒤에, 에너지가 공간에서 시간적으로 얽히면서 생겨난 것이다. (검증 전 예상으로 남김)

중력 쪽 규칙 후보(텐서 3단계까지의 결과, 선형 약한 장):

- 저장 파동의 에너지는 그 자리 시계 몫에, 방향별 하중은 각 막의 자연 길이에 걸린다(원천 결합).
- 막의 실제 길이(틱으로 잰 홉)는 이웃 막과의 곡률 에너지로만 정해지고, 막 혼자서는 돌아갈 원래 길이가 없다.
- 시계 몫은 자기 에너지가 없고, 공간 곡률과 원천을 맞추는 역할만 한다.
- 저장 파동과 장이 주고받는 규칙은 한 에너지 함수에서 나와야 한다: 원천은 σ = −∂ℒ/∂Φ, 파동의 운동량은 m·u̇ (동역학 2-c에서 이를 어기면 에너지가 새어 붕괴함).

현재 구조: 3차원 큐브 격자, 주변 26개에 연결, 가장자리는 반대편 그리드와 같은 것으로 연결(주기 경계).

## 용어 정의

^는 먼 곳(장이 없는 곳) 대비 값이다. 모든 정의는 측정 원칙(틱과 틱으로 잰 홉)으로 읽는다.

**그리드 파라미터 (직접 관측되지 않는 재료값)**

- **m (내부 저장, 관성):** 그리드 안에 저장된 파동이 상태를 바꾸기 어려운 정도.
- **κ (막 결합):** 막이 이웃 그리드의 떨림을 얼마나 강하게 전달하는지.
- **k (자기 복원 스프링):** 이웃과 무관하게, 그리드 내부 파동이 제자리로 돌아가려는 강도. 그리드가 혼자서도 진동하게 만들어 국소 시계 ω_s = √(k/m)를 준다. k가 없으면 파동은 흐르기만 하고 틱을 셀 국소 시계가 없다.
- **Z = √(κm) (임피던스):** 막을 통해 에너지를 밀어 넣기 어려운 정도. 속도 v = a√(κ/m)나 시계와는 무관하고, 이웃끼리 Z가 다르면 그 차이만큼 에너지 일부가 반사된다. 시험 2의 숨은 방향이 바로 이 값이다.

**관측량 (틱과 틱으로 잰 홉에서 나오는 값)**

- **N = ω_s/ω* (시간 몫):** 그 자리 시계가 먼 곳 시계 한 틱 동안 몇 틱 하는지. N < 1이면 시간이 느리게 흐른다.
- **ψ = N/v̂ = √(k̂/κ̂) (공간 몫):** 에너지가 한 홉을 건너는 동안 그 자리 시계가 세는 틱 수(먼 곳 대비). ψ > 1이면 같은 한 홉이 그 자리에서는 더 긴 거리로 잰다.
- **Nψ = k̂/Ẑ (두 몫의 곱):** 시계가 느려지는 정도와 홉이 길어지는 정도가 서로 상쇄되는지를 나타낸다. Nψ = 1이면 시계가 N배 느려질 때 홉은 정확히 1/N배 길어진다. 재료로 보면 자기 복원 스프링 k가 임피던스 Z와 같은 비율로 변한다는 뜻(k ∝ Z)이다.
- **γ = β/α = ln ψ / (−ln N) (공간 휨 대 시간 휨의 비):** 시계가 한 단위 느려질 때 공간이 몇 단위 늘어나는지. 지수 결합에서는 γ = 1과 Nψ = 1이 같다. 시계 지연은 α만 보지만 빛의 휘어짐과 신호 지연은 (1+γ)에 비례하므로 γ는 두 측정을 비교해 잰다. γ = 0이면 시간만 휘고(뉴턴식 절반 휘어짐), γ = 1이면 일반상대성이론과 같다. 1차원에서는 이름표 바꾸기로 지울 수 있어 2차원 이상에서만 물리량이다.

**응력-에너지 (시험 3, 4)** — ℒ = ½m u̇² − ½κ|∇u|² − ½k u²

- ρ = ½m u̇² + ½κ|∇u|² + ½k u² (에너지 밀도)
- p_r = κ u_r² + ℒ, p_t = ℒ, Σp = κ|∇u|² + 3ℒ (압력의 합)
- 정지 진동(물질): Σp/ρ ≈ 0. 속도 v로 움직이는 파속: Σp/ρ = v². 진행파(빛): Σp/ρ = 1 − (μ/ω)² ≈ 1.

**스칼라와 텐서**

- **스칼라 U:** 그리드마다 방향 없는 변형값 하나. 현재 비선형 결합 모형이 이 형태다.
- **텐서 h:** 막(연결 방향)마다 다른 변형값. 3D 큐브의 26개 연결은 방향별 변형을 담을 자리를 자연스럽게 제공한다.
- **헬리시티:** 변형이 진행 방향을 축으로 돌 때의 모양. ±2가 중력파의 두 편광이고, 0(스칼라)과 ±1(벡터)은 GR에 없는 여분 모드다.
- **막 하중 σ_e:** 연결 방향 e(단위벡터 n)의 막이 저장 파동에게서 받는 힘. σ_e = κ_eff⟨(Δ_e u/|e|)²⟩ + ⟨ℒ⟩이고, 연속 극한에서 n·T·n이 된다.

**모드 세기 (텐서 2단계)**

- 텐서 변형 h는 6성분이라, 한 방향으로 퍼지는 변형파는 최대 6가지 모양을 갖는다.
- **출렁이는 모드:** 진동수가 0이 아닌 모양. GR에서는 2개(+, ×).
- **이름표 모드:** 그리드를 밀어 놓은 것과 같은 모양(h = ∂ξ + ∂ξᵀ). 틱과 틱으로 잰 홉으로 구별되지 않는다. 3개.
- **구속 모드:** 진동하지 않고 진공에서는 0으로 강제되는 모양. 원천 근처에서만 생기며 뉴턴 퍼텐셜을 담당한다. 1개.
- **양립 불가능 변형(곡률):** 그리드를 어떻게 밀어도 만들 수 없는 막 변형. 그리드를 밀어서 생기는 변형은 전부 이름표 바꾸기이므로, 중력은 이 부분에만 있다. 클라이너트 결정 모형의 결함이 같은 역할이다.

**자연 길이 규칙 (텐서 3단계)**

- **h00 (시계 몫 변형):** 그 자리 시계 틱 속도의 변화. 시간 몫 N에 해당한다.
- **b1 (맞물림):** 시계 몫과 공간 곡률 R이 서로 얼마나 묶여 있는지. 정적 물질 주변에서 γ = −b1/2.
- **b2 (시계 몫의 자기 에너지):** 시계 몫이 스스로 갖는 에너지. 정적 γ는 바꾸지 않고 중력 세기만 바꾼다.
- **K (막의 자연 길이 스프링):** 막이 자기 원래 길이로 돌아가려는 힘. 측정 원칙상 0이어야 한다.
- **시공간 밀기:** 그리드 밀기(ξ_i)에 틱 다시 매기기(ξ_0)와 시간에 따라 변하는 밀기까지 포함한 이름표 바꾸기.

**중력파 측정 (동역학 2-a)**

- **고리 표지:** xy 평면에 반지름 6으로 놓은 시험 그리드 16개. 시간 게이지에서는 좌표에 고정된 표지가 자유 낙하하므로, 중심에서 각 표지까지 틱으로 잰 거리가 그대로 물리적 거리다.
- **TT 성분:** 진행 방향에 수직하고 대각합이 0인 막 변형. + 편광(xx − yy)과 × 편광(xy) 두 가지뿐이다.
- **자라는 이름표 성분:** 초기 상태가 구속조건을 완전히 만족하지 않으면, 시간에 비례해 자라는 이름표 성분(틱 다시 매기기를 시간에 따라 바꾼 것)이 생긴다. 물리적으로 보이지 않지만 h 그림에는 나타난다.

**자기 묶임과 느린 극한 (동역학 2-c)**

- **빠른 떨림과 느린 움직임:** 저장 파동은 시계 진동수 μ로 빠르게 떨고, 덩어리 전체는 훨씬 느리게 움직인다. 장이 정적이라고 보는 근사는 느린 부분에만 맞는다.
- **포락선 φ:** 빠른 떨림을 걷어 낸 파동의 크기와 위상. u = Re[φ e^{−iμt}]. 같은 격자 규칙의 느린 극한에서 φ는 슈뢰딩거-뉴턴형 방정식을 따른다.
- **바닥 상태(스스로 묶인 덩어리):** 퍼지려는 경향과 자기 중력이 균형을 이룬 모양. 허수 시간 계산으로 구한다. 크기는 대략 1/(GMμ²).

## 수식 체계

시간 몫 N은 시계 진동의 위상에서, 공간 몫 ψ는 에너지가 한 칸을 건너는 고유시간에서 나온다. a는 격자 간격, ω*는 먼 곳 시계 진동수, ^는 먼 곳 대비 값이다.

**격자 파동** (m: 내부 저장, κ: 막 결합, k: 자기 복원 스프링)

```latex
m\,\partial_t^2 u = \nabla\cdot(\kappa\nabla u) - k\,u
```

**시간과 공간의 창발**

```latex
N = \frac{\omega_s}{\omega_*},\quad \omega_s=\sqrt{k/m},\qquad \psi = \frac{N}{\hat v} = \sqrt{\hat k/\hat\kappa} = \frac{1}{\hat\xi},\quad v = a\sqrt{\kappa/m},\ \xi = v/\omega_s
```

```latex
ds^2 = -N^2 c_*^2\,dt^2 + \psi^2\,dx^2,\qquad \frac{dx}{dt} = \frac{N}{\psi} = \hat v
```

**비 1 조건** (Z = √(κm)은 임피던스)

```latex
N\psi = \frac{\hat k}{\hat Z} = 1 \iff \gamma = 1
```

**비선형 결합** (저장 파동이 막의 정적 변형 U를 만들고, U가 파라미터를 바꿈)

```latex
m=m_0e^{aU},\ \kappa=\kappa_0e^{-bU},\ k=k_0e^{cU};\quad \alpha=\tfrac{a-c}{2},\ \beta=\tfrac{b+c}{2};\quad N=e^{-\alpha U},\ \psi=e^{\beta U},\ \gamma=\beta/\alpha
```

Nψ = 1은 α = β와 같고, 약한 장에서 지수 계량은 γ = 1, β_PPN = 1을 준다. 단, U가 스칼라 하나인 이 형태는 정지한 원천에서만 쓸 수 있다(시험 4). 움직이는 원천까지 일관되려면 U를 방향별 변형(텐서)으로 바꿔야 한다.

**파라미터 분해** (시험 2): (a, b, c) 세 방향은 다음으로 나뉜다.

- α = (a−c)/2: 시계 몫. 모든 차원에서 물리량.
- β = (b+c)/2: 틱으로 잰 홉 몫. 2차원 이상에서 물리량. 1차원에서는 이름표 바꾸기 J = e^{jU}가 (a, b, c)를 (j, j, j)만큼 옮겨 β를 지울 수 있다.
- 숨은 방향 (a, b, c) → (a+t, b−t, c+t): m, κ, k에 같은 배수 e^{tU}를 곱해 임피던스 Z만 바꾼다. 틱/홉 측정에서는 기하 극한에서 보이지 않고, 반사와 (파장/장 변화 규모)² 크기의 보정으로만 드러난다.
- k ∝ Z(Nψ = 1)는 숨은 방향에서 k와 Z가 함께 변해 유지되므로 이름표 선택이 아니다. 물리량 하나 γ = 1을 고정하는 조건이고, 측정 원칙만으로는 정해지지 않는다.

**원천 구조** (파동이 N과 ψ에 같은 방식으로 결합할 때, 1차원에서 m = ψ/N, κ = N/ψ, k = Nψμ²)

```latex
\nabla^2\Phi = 4\pi G(\rho + \textstyle\sum p),\qquad \nabla^2\Psi = 4\pi G\rho
```

정지한 물질은 Σp = 0이라 Φ = Ψ(비 1), 빛은 Σp = ρ라 시간 몫 원천이 2ρ다. 이 형태는 막 변형이 텐서이고 원천이 응력-에너지 성분 그대로일 때 나오는 형태(선형화된 일반상대성이론)와 같다. 막 변형이 스칼라이면 움직이는 이름표와 맞는 원천은 ρ−Σp뿐이다(시험 4).

**묶인 계의 압력 상쇄** (시험 3-a, 정적 평형의 비리얼 정리): 벽 반지름 R, 부피 V, 벽이 받는 압력 P일 때

```latex
\int \Sigma p_{\text{파동}}\,dV = 3VP,\qquad \int \Sigma p_{\text{벽}}\,dV = -3VP\ \ (\text{라플라스 식 } P = 2\sigma/R)
```

따라서 묶인 정적 계는 벽까지 합친 압력 적분이 0이고, 원천이 ρ든 ρ+Σp(벽 포함)든 먼 곳 장은 총에너지로만 정해진다.

**움직이는 이름표와 스칼라 원천** (시험 4): 정지 에너지 M인 파속이 속도 v로 움직이면 E = γM, Σp = γMv². 스칼라 밀도의 부피 적분은 1/γ배가 되어야 하므로

```latex
\int(\rho-\Sigma p)\,dV = \gamma M(1-v^2) = M/\gamma\ \ (\text{일관}),\qquad \int\rho\,dV = \gamma M,\ \ \int(\rho+\Sigma p)\,dV = \gamma M(1+v^2)\ \ (\text{불일치})
```

**텐서 결합의 게이지 조건**: 텐서 변형 h가 응력-에너지와 h_ij T^ij로 결합할 때 이름표 바꾸기 h_ij → h_ij + ∂_iξ_j + ∂_jξ_i에 무관하려면

```latex
\partial_j T^{ij} = 0
```

이어야 한다(국소 보존). 시험 3-a의 비리얼 정리가 이 보존을 확인한 결과다. 격자에서는 연속 평행 이동 대칭이 없어 이 보존이 (a/σ)², (qa)² 크기로만 성립한다(격자 보존 오차 측정).

**막 하중과 응력 텐서** (텐서 1단계): 평면파 u = cos(q·x − ωt)에 대해 격자 시간 평균은 정확히 ⟨(Δ_e u)²⟩ = 1 − cos(q·e), ⟨ℒ⟩ = 0이다. 따라서

```latex
\sigma_e = \frac{\kappa_{\text{eff}}}{|e|^2}\,\bigl(1-\cos(q\cdot e)\bigr) = n_i n_j T_{ij} + O\bigl((qa)^4\bigr)
```

이고, O((qa)⁴) 항은 텐서로 묶이지 않는 입방 격자 보정이다.

**이름표 무관한 막 결합 에너지는 하나뿐** (텐서 2단계): 이웃 막 결합(2계 미분)의 이차 에너지 일반형

```latex
V = c_1\,q^2\,h_{ij}h_{ij} + c_2\,(q_ih_{ij})(q_kh_{kj}) + c_3\,(q_iq_jh_{ij})\,h + c_4\,q^2h^2
```

에 "아무 변형에 그리드 밀기를 더해도 에너지가 그대로"를 요구하면 해는 하나뿐이다.

```latex
(c_1, c_2, c_3, c_4) = (1,\,-2,\,2,\,-1)
```

이것은 선형화된 아인슈타인-힐베르트 에너지의 공간 부분과 같다.

**자연 길이 규칙의 정적 에너지** (텐서 3단계): 시계 몫 h00과 막 변형 h_ij에 대해, R(h) = q_iq_jh_ij − q² tr h, 막 방향 단위벡터 n_e(13개)일 때

```latex
F = V(h) + b_1\,h_{00}\,R(h) + b_2\,q^2h_{00}^2 + K\sum_e (n_e\cdot h\cdot n_e)^2 - \bigl(h_{00}\,\rho + h_{ij}T_{ij}\bigr)
```

정지한 점 물질(ρ = 1, T_ij = 0)에 대해

```latex
\gamma_{\text{eff}} = \frac{h_{zz}}{h_{00}}\Big|_{q\perp z} = -\frac{b_1}{2}\quad (K = 0),\qquad q^2h_{00} = \text{일정}\ (1/r\ \text{장})
```

**시공간 이름표 무관성이 정하는 계수** (텐서 3단계): 시계 몫까지 포함한 h_μν와 4-파수 q에 대해 η로 묶은 일반형에 시공간 밀기 h_μν → h_μν + q_μξ_ν + q_νξ_μ 무관성을 요구하면 해는 하나뿐이고 (1, −2, 2, −1)이다. 이를 정적으로 줄이면

```latex
b_1 = -2,\qquad b_2 = 0,\qquad \text{운동 에너지}\ \ \dot h_{ij}\dot h_{ij} - \dot h^2\ \ (\text{비}\ -1)
```

이 되어 γ = 1이 나온다. 전제: 중력 쪽 에너지도 빛과 같은 움직이는 이름표(같은 빛의 속도)를 따른다.

**장 → 그리드 재료값 → 휨** (동역학 1): 규칙이 준 Φ, Ψ = γΦ로 N = e^{Φ}, ψ = e^{−Ψ}를 만들고, 빛이 지나는 평면 위 2D 격자의 재료값을 m = ψ²/N, κ = N, k = Nψ²μ²로 둔다. 속도 v인 파속의 휨각 예측은

```latex
\theta = \frac{2GM}{b\,v^2}\,\bigl(1+\gamma v^2\bigr)
```

이다. θv²/(2GM/b)를 v²에 대해 맞추면 기울기/절편이 γ가 된다.

**막 변형파의 시간 진행** (동역학 2-a): 시간 게이지(h_0μ = 0)에서 파수마다

```latex
K\,\ddot h = -V(s)\,h,\qquad K(h) = h_{ij}h_{ij} - h^2,\qquad s_i = \tfrac{2}{a}\sin\tfrac{q_ia}{2}
```

축 방향 격자 군속도는 cos(qa/2)이다. 고리 표지까지의 거리는 L = ∫(1 + ½ n·h·n) ds.

**저장 파동과 장의 주고받기** (동역학 2-c): 평면 위 2D 격자(Ψ = Φ)에서 m = e^{−3Φ}, κ = e^{Φ}, k = e^{−Φ}μ². 에너지가 정확히 보존되려면

```latex
\dot\pi = \nabla\cdot(\kappa\nabla u) - k\,u,\quad \pi = m\,\dot u,\qquad \sigma = -\frac{\partial\mathcal L}{\partial\Phi} = \tfrac32 e^{-3\Phi}\dot u^2 + \tfrac12 e^{\Phi}|\nabla u|^2 - \tfrac12 e^{-\Phi}\mu^2u^2
```

σ는 시간 평균하면 ρ와 같지만 순간값은 2μ로 평균의 두 배 폭으로 출렁인다.

**느린 극한** (동역학 2-c): u = Re[φ e^{−iμt}]일 때 같은 격자 규칙의 느린 극한은

```latex
i\,\partial_t\varphi = -\frac{1}{2\mu}\,\Delta_{\text{격자}}\varphi + \mu\,\Phi\,\varphi,\qquad \Phi(x) = -G\!\int\!\frac{\rho(x')\,d^2x'}{|x-x'|},\quad \rho = \tfrac12\mu^2|\varphi|^2
```

이고 G = C_RULE/(8π)(규칙 값)이다. 평면 위 두 점질량의 원 궤도 속도는 v² = GM/(4r₀).

**막 변형파의 방출** (동역학 2-b): 운동 에너지 ḣ:ḣ − ḣ²와 정적 에너지 F = V(h) − h_ij T_ij를 합친 라그랑지안에서 K ḧ = −V h + ½T이고, 두 편광(TT) 부분은 K = 1, V = s²로 다른 성분과 정확히 분리된다.

```latex
\ddot h^{TT}_{ij} = \Delta_{\text{격자}} h^{TT}_{ij} + \tfrac12 T^{TT}_{ij},\qquad 16\pi G = \tfrac12 \iff G = \frac{1}{32\pi}\ (\text{정적 } G\text{와 같은 값})
```

원천이 보존되면(∂_t T^{0i} + ∂_j T^{ij} = 0) 먼 곳에서

```latex
h^{TT}_{ij} = \frac{4G}{r}\int T^{TT}_{ij}\,d^3x = \frac{2G}{r}\,\ddot I^{TT}_{ij}(t-r),\qquad \int T_{ij}\,d^3x = \tfrac12 \ddot I_{ij}
```

질량 m 둘이 반지름 r₀, 각속도 ω로 돌면 정면 진폭 r·h = 8Gmω²r₀². 원 궤도에서 운동 응력 ∫ρv_iv_j는 ½Ï_ij의 회전 성분 중 정확히 절반이고, 나머지 절반은 두 덩어리를 묶는 장의 응력이 채운다.

```latex
t_{ij} = \frac{1}{4\pi G}\bigl(\partial_i\Phi_1\partial_j\Phi_2 + \partial_i\Phi_2\partial_j\Phi_1 - \delta_{ij}\nabla\Phi_1\cdot\nabla\Phi_2\bigr),\qquad \partial_j t_{ij} = \rho_1\partial_i\Phi_2 + \rho_2\partial_i\Phi_1
```

크기가 있는 덩어리는 상대의 끌림이 덩어리 안에서 고르지 않으므로(조석), 모양을 유지하는 내부 응력이 더 필요하다. 폭 σ인 가우스 덩어리에서

```latex
\tau^{(b)}_{ij} = \sigma^2\,\rho_b\,\partial_i\partial_j\Phi_{\text{상대}}\big|_{\text{중심}},\qquad \text{없으면 부족분} \approx \frac{\sigma^2}{6 r_0^2}
```

**푸리에 TT 투영의 근거리 모양** (동역학 2-b): 점 원천 T = Q δ(x) e^{−iΩt}의 정확한 나가는 해는 F₀ = e^{iΩr}/4πr, F₂ = (e^{iΩr} − 1)/(4πΩ²r), F₄ = (e^{iΩr} − 1)/(4πΩ⁴r) + r/(8πΩ²)로

```latex
h_{ij} = \tfrac12\Bigl[Q_{ij}F_0 + Q_{kj}\partial_i\partial_kF_2 + Q_{ik}\partial_k\partial_jF_2 - \tfrac12\delta_{ij}Q_{kl}\partial_k\partial_lF_2 + \tfrac12 Q_{kl}\partial_i\partial_j\partial_k\partial_lF_4\Bigr]
```

이고, r·h는 kr ≈ 2에서 먼 곳 값의 0.61, kr ≈ 4에서 0.95이며 kr ≳ 8에서야 3% 안으로 들어온다.

**이름표 바꾸기 변환** (좌표 x → ξ, J = dx/dξ)

```latex
m' = mJ,\qquad \kappa' = \kappa/J,\qquad k' = kJ
```

## 관련 연구와 겹치는 부분

"GR이 그리드 규칙에서 창발한다"(방향 A)는 완전히 증명된 적이 없다. 같은 질문을 여러 방향에서 시도한 연구가 있고, 각자 일부만 성공했다.

**구-원 모형과의 겹침**

- 같은 점
  - 3D 큐브 격자, 국소 규칙, 유한한 격자 간격.
  - 방향별 텐서 변형을 기본 재료로 둔다.
  - 이 실험의 측정 원칙("그리드 번호는 의미 없음")은 구-원 모형에서 창발하는 선형화된 미분동형 게이지 대칭과 같은 내용이다. 시험 1이 바로 이 대칭을 시험했다.
  - 여분 모드(헬리시티 0, ±1)를 없애야 한다는 같은 과제. 이름표 무관성이 ±1을 없애고, 헬리시티 0은 별도 조건이 필요하다.
  - 시간이 절대적(선호 좌표계)이고 비선형성이 미해결.
- 다른 점
  - 구-원은 계량(텐서)을 처음부터 기본 자유도로 넣었다. 이 실험은 저장된 파동이 막을 변형시켜 텐서가 생기는 것을 목표로 한다(물질이 먼저).
  - 구-원은 물질 결합이 미확립이다. 이 실험은 물질 쪽(응력-에너지, 비리얼 정리, 움직이는 이름표)을 시험 3-a, 4에서 먼저 확인했고, 동역학 2-c에서 물질과 장이 함께 움직이는 궤도까지 확인했다.
  - 구-원은 양자 큐비트 모형이고, 이 실험은 고전 파동 모형이다. 고전 모형에서는 선형 분산(ω ∝ k)이 이름표 무관한 에너지에서 바로 나온다(텐서 2단계). 구-원의 분산 난관은 양자 모형에서 이 구조가 저절로 생기게 하는 데서 왔다.
- 연결 고리: 텐서 결합 h_ij T^ij가 이름표 무관하려면 ∂_j T^ij = 0이어야 하고, 시험 3-a가 이를 확인했다. 물질 쪽 조건은 이미 갖춰져 있다.

**텐서 막 규칙이 만족해야 할 조건** (선행 연구에서 정리)

1. 26개 연결마다 방향별 변형값 → 대칭 텐서 h_ij로 모인다. (원천 쪽은 텐서 1단계에서 확인: 막 하중이 응력 텐서 6성분을 정확히 담음)
2. 막 변형의 에너지가 이름표 바꾸기 h_ij → h_ij + ∂_iξ_j + ∂_jξ_i에 무관해야 한다(헬리시티 ±1 제거). (텐서 2단계: 이 조건을 만족하는 이웃 결합 에너지는 하나뿐. 동역학 2-a: 이름표 성분은 시간이 지나도 정확히 정지)
3. 헬리시티 0(스칼라) 모드가 없거나 원천과 맞물려 사라져야 한다(클라이너트의 여분 종파 문제). (텐서 2단계: 그 유일한 에너지에서는 진동하지 않는 구속 모드 1개로 남음. 텐서 3단계: 막의 자연 길이 스프링 K가 있으면 이 구조가 깨지고 가둠이 생김 → K = 0)
4. 남는 두 편광의 분산이 선형(ω ∝ k)이고 속도가 빛과 같아야 한다(구-원의 난관). (텐서 2단계: 연속 극한에서 속도 1.000. 동역학 2-a: 시간 진행에서도 두 편광만 퍼지고 속도는 격자 예측과 맞음. 단, 중력 쪽도 빛과 같은 움직이는 이름표를 따른다고 둔 결과이며, 아직 가정)
5. 원천은 저장 파동의 응력-에너지 T^ij이고, 그 결과 시간 몫 ρ+Σp, 공간 몫 ρ, γ = 1이 나와야 한다. (텐서 3단계: 정지 물질에서 γ = 1과 1/r 확인. 맞물림 b1 = −2는 시공간 이름표 무관성에서 유일하게 정해짐. 동역학 1: 그 장 속 격자 파동이 잰 γ = 1.04로 휨. 동역학 2-c: 같은 G로 두 덩어리가 케플러 궤도를 돎. 동역학 2-b-1: 같은 G로 4중극 방출, 1.5% 안 일치)
6. 최종 목표: 이 규칙이 손으로 넣은 것이 아니라 저장 파동과 막의 역학에서 나와야 한다. (텐서 2·3단계: 막 결합 에너지, 맞물림, 시계 몫 에너지, 운동 에너지 비가 모두 "시공간 이름표 무관 + 이웃 결합"에서 유일하게 정해짐. 남은 것: 중력 쪽이 빛과 같은 속도를 갖는 이유, 장이 퍼지는 파동으로 움직이는 완전 결합(지연 포함), 비선형)

## 규칙 변천 이력

규칙은 에너지 흐름 → 처리 한계 → 문턱 발화 → 파동 모형 순으로 바뀌었다.

1. 출발 질문: 세계는 시간 그리드를 움직이는 에너지를 인지가 인식한 결과인가. 이후 인지를 제외하기로 함.
2. 시간은 전달되는 순수 에너지와 연결되며, 전달 총량으로 정의 → 부호 문제(빠른 시계가 느려지는 현상과 반대).
3. 처리 속도에는 한계, 저장에는 한계가 없음. 쌓인 에너지가 이웃 처리량을 늘려 중력과 굴절을 만듦.
4. 공간은 그리드 간 전달이 측정된 개념, 빛은 공간과 다름. 두 곡률의 비는 1이어야 함.
5. 그리드 간 전달 속도는 모두 c로 같음. 저장이 많을수록 처리가 느려짐.
6. 문턱 발화: 연결된 모든 그리드에 같은 양, 일정 이상 쌓여야 발산, 동시 발화는 교환으로 상쇄. 시간은 공통 틱 없이 저장과 이동만으로 판단.
7. 빅뱅 초기 조건, 그리드 수 고정, 총 에너지는 임계값 합보다 낮을 수 있음.
8. 구조 변경: 무작위 연결 → 고리(연결 2개) → 3D 큐브(26방향, 주기 경계). 방향성 에너지와 8·16방향 확산도 시험.
9. 저장 능력은 무한에 가깝고 저장될수록 데이터적으로 커져 통과가 느려짐, 특정 저장량에서 이동이 0에 수렴.
10. 전면 수정: 막의 떨림으로 전달하고 내부에 파동으로 저장하는 현재 규칙.
11. 측정 원칙 수정: "시계 틱과 홉 수만 의미가 있다" → "시계 틱과 틱으로 잰 홉만 의미가 있다" (시험 1에서 원시 홉 수가 표현마다 달라짐).
12. 중력 쪽 규칙 후보 추가: 하중이 막의 자연 길이를 바꾸되 막 자신은 돌아갈 원래 길이가 없음(K = 0), 시계 몫은 자기 에너지 없이 곡률과 원천을 맞춤(텐서 3단계).
13. 예상 추가: 중력은 시간과 공간이 만들어진 뒤, 에너지가 공간에서 시간적으로 얽히면서 생겨난 것.
14. 공개 계획 추가: 실험 전체를 웹페이지로 시각화. 실험마다 그리기용 데이터 저장, 관측 가능한 값만 그림.
15. 주고받기 규칙 추가: 저장 파동과 장이 주고받는 원천과 운동량은 한 에너지 함수에서 나와야 함(동역학 2-c).
16. 방출 원천 조건 추가: 묶인 계가 내보내는 막 변형파의 원천은 보존되는 전체 응력(운동 응력 + 묶는 장 자신의 응력 + 내부 응력)이어야 하며, 운동 응력만으로는 절반만 나옴(동역학 2-b-1).

## 남은 과제와 열린 질문

가장 먼저 풀 과제는 동역학 2-b-1에서 손으로 넣은 "묶는 장의 응력"이 그리드 규칙에서 저절로 나오는지(막 변형 자신의 에너지가 원천이 되는 비선형 자기 결합)이다. 2-b-1은 원천이 보존되면 정적 G 그대로 방출된다는 것을 보였지만, 보존에 필요한 장의 응력은 뉴턴 장에서 계산해 넣었다. 순서: 시험 1~4(완료) → 텐서 1~3단계(완료) → 동역학 1(완료) → 2-a 자유 중력파(완료) → 보존 오차 측정(완료) → 2-c 끌림과 묶임(완료) → 2-b-1 궤도 원천의 방출(완료) → 장의 응력의 출처(비선형) → 2-b-2 방출에 따른 궤도 줄어듦.

- [ ] 장 쪽 비율: 시간 몫은 ρ+Σp, 공간 몫은 ρ를 받는 형태를 측정 원칙에서 끌어낼 수 있는가
  - [x] 시험 1: 모형이 이름표 무관성을 지키는가 (연속 극한에서 지킴, 격자 분산은 O(h²))
  - [x] 시험 2: 숨은 방향은 임피던스 하나. k ∝ Z는 상수 추가가 아니라 물리 조건 γ = 1 하나이며, 측정 원칙만으로는 정해지지 않음 → 장 방정식에서 와야 함
  - [x] 시험 3-a: 그리드 파동은 비리얼 정리를 지킴(벽 하중 = 파동 압력 적분). ρ+Σp 원천은 벽 응력을 넣어야만 보존과 맞음(폰 라우에). 단, 묶인 정적 계로는 ρ만 원천과 ρ+Σp 원천을 구분하지 못함
  - [x] 시험 4: 움직이는 파속으로 판정. 스칼라 U는 ρ−Σp만 허용 → 빛이 중력을 만들지 못하고 γ = 1과 모순 → 스칼라 U 배제. ρ+Σp / ρ 형태는 텐서 막 변형에서 나옴
  - [x] 관련 연구 확인: 구-원 격자 모형, 클라이너트 세계 결정, 바인버그-위튼 정리, 제이콥슨, 아날로그 중력 (위 섹션)
  - [x] 텐서 1단계: 저장 파동의 막 하중이 응력 텐서 6성분을 담는가 → 담음(26·18·14연결). 6연결은 3성분뿐
  - [x] 텐서 2단계: 막 결합 규칙의 모드 세기 → 이름표 무관한 이웃 결합 에너지는 하나뿐이고 GR과 같은 2 + 3 + 1 구조. 그리드를 밀어서 생기는 변형은 전부 이름표 바꾸기
  - [x] 텐서 3단계: 자연 길이 규칙 → 정지 물질에서 γ = 1, 1/r. 시공간 이름표 무관성이 b1 = −2, b2 = 0, 운동 에너지 비 −1을 유일하게 정함. 막의 자연 길이 스프링 K는 원칙에 어긋나고 가둠을 만듦 → K = 0
  - [x] 동역학 1: 규칙이 만든 장을 그리드 재료값으로 바꾸고 격자 위로 파속을 보냄 → 끌림, 잰 γ = 1.04, 빛 극한에서 약 2배. 대조(시간 몫만)는 γ = 0.02
  - [x] 동역학 2-a: 3D 격자에서 막 변형파 시간 진행 → + / × 두 편광만 퍼짐, 이름표 성분은 정지, 속도는 격자 예측과 맞음. 웹용 데이터 저장

  - [ ] 동역학 2-b-2: 방출이 궤도 에너지를 가져가 궤도가 줄어드는지(되먹임). 4중극 방출률 P = (32/5)Gμ²a⁴ω⁶ 크기와 맞는지. 동역학 2-c의 실제 묶인 덩어리를 원천으로 쓰려면 2D 평면 느린 극한을 3D로 넓혀야 함
  - [ ] 실제 파동(빠른 떨림 포함)과 장의 완전 결합: 장을 정적으로 풀지 않고 파동 방정식으로 움직이게 하면 동역학 2-c의 에너지 누수가 사라지는지
  - [ ] 동역학 1을 웹용 프레임 저장 형태로 다시 돌리기
  - [ ] 중력 쪽이 빛과 같은 속도를 가져야 하는 이유(같은 막이 두 역할을 하기 때문인지)
  - [ ] 비선형: 막 변형 자신의 에너지도 원천이 되는 자기 결합이 GR의 비선형 항을 주는지. 첫 시험: 2-b-1에서 손으로 넣은 묶는 장의 응력(뉴턴 극한의 장 응력)이 막 결합 에너지의 2차 항에서 나오는지
  - [ ] 예상 검증: 중력이 "시간과 공간이 생긴 뒤 에너지가 공간에서 시간적으로 얽히며" 생긴다는 예상을 시험할 수 있는 형태로 만들기
  - [ ] 시험 3-b: 자기 중력으로 묶인 덩어리(동역학 2-c)가 비리얼 정리를 지키는지 보는 반증 시험. 이제 묶인 물체가 있으므로 진행 가능

- [ ] 강한 장(지평선 반지름 R ∝ M인가), 회전 효과
- [ ] 격자 분산과 방향성이 관측 한계 안에 드는가 — 시험 4에서 파수×격자 간격 0.25부터 로런츠 위반이 보임. 텐서 2단계에서 중력파 속도도 파수×격자 간격 0.3에서 0.4% 느려짐. 동역학 2-a에서 파장 4칸은 속도가 0.78까지 떨어짐. 관측 한계에서 격자 간격의 상한을 정하기
